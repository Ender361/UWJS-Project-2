# UWJS-Project-2

URL: https://Ender361.github.io/UWJS-Project-2/

Summary: This project allows the user to get an organized list of Pokémon from an external API and then view specific details on each of the Pokémon in the list. It
also allows the user to add Pokémon to a 'team' which can contain up to 3 Pokémon and details additional information about each member and the team as a whole.

1. What worked well in this project (what was easy/straightforward)?

I found working with the API to be very easy and straightforward. The API didn't have usage limits and displayed data very cleanly which made it easy to use. 
I also really liked working with React Routes, I found them very intuitive.

2. What didn't work well (what was difficult to understand or parse)?

The most difficult part for me was trying to get data fetched from the API, along with other details like user submission, to easily be stored across multiple routes.
It was also just the largest React project I have ever made and keeping it all organized and making sense was hard. It was difficult to know exactly what to do next.

3. What changes would you make to this project now that it's deployed?

The biggest issue I see in my project is that it calls the API many different times, this is okay because the API I'm working with has no usage restrictions, but it
doesn't feel like good practice. If I were to go back and recreate this project, I would put more functionality into earlier components and make it easier to
share data from one component to another. 

4. What would you improve and/or add to this project now that it's deployed?

I had planned to add a battle feature to the app but ran out of time to add this, I am proud of my work and worked hard to create this but I am disappointed I wasn't
able to implement the battle feature, that would definitely be something I would work on next. Aside from that I'd like to clean up the API calls.
